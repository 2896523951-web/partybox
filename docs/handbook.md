# 聚会游戏机 · Party Box

一台笔记本 + 一屋人的手机，就能开一晚上游戏局。
不用装 App、不用联网、不用买耳返。玩家扫码进房间，手机只显示**该他一个人看的东西**。

十三个游戏，随时切换，比分累计。再加一件跨游戏的小工具：往任何一个人的耳机里放一段声音。

```
传声筒 · 谁是卧底 · 听歌识曲 · 报数抢答 · 你们认了吗
数字炸弹 · 你画我猜 · 舞蹈狼人杀 · 笨蛋杀手
好奇宝 · 接力猜词 · 重复就打飞 · 狼人杀
```

一晚上怎么串起来：节目单（暖场 → 主游戏 → 惩罚 → 收尾）→ 主持台可开自动推进 →
没上场的人在手机上下注 → 散场出总榜（每人一个称号）+ 复盘 + 导出 CSV。过年那几天可以一键换红金皮肤。

包里另附两本可打印的册子：**操作手册.docx**（从插电到收场，主持人要做的每一步，23 页）与
**游戏介绍.docx**（13 个游戏各一页规则，18 页）。不想翻这份 README，直接打开这两本。

## 三步跑起来

```bash
# 1. 需要 Node.js 18+（node -v 检查）
# 2. 启动
node server.js
#    Windows 也可以双击 start.bat
# 3. 浏览器打开 http://localhost:3210/host
```

终端会打印两条地址：

```
主持台（局域网）http://192.168.1.23:3210/host?k=8a3f1c02
玩家入口        http://192.168.1.23:3210
```

- **只把「玩家入口」投给玩家**（主持台页面上有二维码）。
- 带 `?k=` 的那条是主持台地址，里面的密钥挡住玩家翻 `/host`。本机用 `localhost` 打开不需要密钥。
- 想固定密钥：`HOST_KEY=abc123 node server.js`（Windows：`set HOST_KEY=abc123 && node server.js`）。

> 注意：主持台、投屏、玩家必须在**同一个 Wi-Fi**。投屏的扫码页会写出当前 Wi-Fi 名字（`同一 Wi-Fi：xxx`），
> 玩家照着对一眼就知道自己连错没有——现场十次「扫了打不开」有九次是连在另一条网上。
> 场地 Wi-Fi 若开了「AP 隔离」（设备之间不能互访），手机连不上电脑，换手机热点。

## 三条线，各管一件事

| 入口 | 谁用 | 干什么 |
|---|---|---|
| `/host` | 主持人 | 切游戏、发题、开抢、计分、使坏。带密钥 |
| `/play` | 每人手机 | 只看自己该看的：词、身份、投票、抢答 |
| `/screen` | 电视 / 投影 | 比分、倒计时、票数。**只读，永不发声** |

## 声音怎么走（这是整套东西的地基）

```
房间里的公共音乐 ──▶ 你自己的手机 / 音响随便放     ← 这台机器不参与
音频库里的歌 ──▶ 每台手机本地各放一份（仅舞蹈狼人杀）  ← 只有耳机里响
私密音效（你传的 / 曲库里的歌）──▶ 某一个人的耳机       ← 只有他听得到
```

三条铁律：

1. **公共音乐不归这台机器管。** 想放歌，直接用你自己的播放器接音响就行；主持台右栏那个「试听」只是给游戏音频试声音用的。
2. **要进游戏的音频放「音频库」。** 传进去的歌可以在游戏面板里选（舞蹈狼人杀换真歌、传声筒灌杂音、左栏「耳机里放」）。**没有内置音效**——想放什么就传什么，见下面「私密音效只有真文件」那条。舞蹈狼人杀选了真歌时，每台手机从主持机本地拉自己那一份，服务端一个字节音频都不推流。
3. **投屏永不发声。** 电视浏览器再放一遍会打架、出回声。

所以每台手机**必须戴耳机** —— 不然「只有他能听到」的效果直接穿帮。进场页会强制勾选「已戴耳机」，主持台的玩家卡片上也会标出来。

## 十三个游戏怎么玩

| 游戏 | 玩家手机 | 主持人做什么 |
|---|---|---|
| **传声筒** | 开局先自己挑棒次（第 1 棒看词、最后一棒猜，先到先得，挑满自动开始）；第 1 棒按住看词，中间人只看到「轮到你」，最后一棒是输入框 | 开始（没挑的随机排）/ 换一题 / 判对判错 / 给某人灌杂音（灌哪种自己选，也能停） |
| **谁是卧底** | 按住看自己的词；投票阶段直接选人。三种玩法：标准 / 白板 / 双卧底 | 发词、下一位、开始投票、计票、摊牌；下拉里切玩法、换词库、调卧底人数（下一局生效） |
| **听歌识曲** | 大圆抢答按钮，开抢前是灰的按不动（不罚分、不禁答） | 用你自己的设备放歌，点「开抢」，判对错 |
| **报数抢答** | 大圆按钮，抢跑扣分 | 开始（随机 1.5–5 秒后开抢）、立刻开抢、结束 |
| **你们认了吗** | 每人匿名投两个人 | 换题、截止、看实时票数 |
| **数字炸弹** | 轮到谁谁出输入框 | 开始、跳过、公布炸弹 |
| **你画我猜** | 画手看词，其他人在手机上输答案 | 换题、判某人猜中、公布答案；面板上有每人的猜中/猜测次数和命中率 |
| **舞蹈狼人杀** | 按住看身份。跳舞时耳机里放音乐，底部显示进度（音量由主持人统一控制）；狼王那台进度照走、只是没声音 | 选曲目（内置合成 / 音频库里的歌）、调耳机音量、拖曲目进度、停音乐、同化某人（动作在台上，这里只记账）、投票结算 |
| **笨蛋杀手** | 老板按住看目标；杀手一排「XXX 走你」；好人按住看身份。接头动作只发给老板和杀手 | 任务进度 +1、开始投票、统计票数 |
| **好奇宝** | 抽到的人投「吃 / 不吃」，其余人看戏 | 重抽队伍、开始投票、结算本轮 |
| **接力猜词** | 第 1 棒看词画，中间轮流「描述 / 再画」，最后一棒猜 | 换题、判对错、选方言、选词库；面板上按队统计猜对 / 没中 |
| **重复就打飞** | 显示你和谁一组 + 本轮主题 | 放音乐、停音乐（自动配对出题）、逐组判「重复」、结算 |
| **狼人杀** | 狼人夜里看到队友和刀口，预言家看验人结果，女巫看到刀口决定救或毒 | 推进夜晚流程、天亮结算、投票、猎人开枪 |

几个玩法上的取舍，是刻意这么定的：

- **谁是卧底有三种玩法，但手机上长得一模一样。** 标准（大多数人一个词、卧底拿近义词）、白板（一个人没词，全靠听别人描述猜）、双卧底（两个卧底同一个词，开场就互相知道，至少要 5 个人）。白板的词卡上写着「白板」，但字号、位置、遮罩文字和别人的词卡完全一致 —— 空着屏或者换个样式，桌上一眼就认出来了。卧底的「同伙：XXX」放在遮罩下面，和词一起按住才看得见，不走 hint（hint 在遮罩外面，多出来的那一行本身就是身份）。切玩法只影响下一局：这局的词已经发下去了，中途改规则会让手上拿着词的人无所适从。
- **传声筒不许打字。** 手机只负责发题、计时、判分、使坏，传递必须靠嘴和身体。一旦变成打字接力，节目效果归零。
- **你画我猜画在纸上。** 手机不做画板——小屏画画体验差，纸笔更自然。手机只管「谁看题、谁在画、传没传完」。
- **「耳机里放一段」不是游戏，是主持台的工具。** 左栏点一个人，下面就出现「耳机里放」：选一段音效或曲库里的歌，点「放」，只有他那台手机响。谁走神、谁拖节奏，随手一下就够了，不必先开一局游戏。三条规矩是死的：没戴耳机的人这栏不出现（放出来是全场公放，不是刚才那回事）；12 秒自动收，不用记着按停；换人先停上一个，不会两台一起响。手机正在放舞曲时（舞蹈狼人杀）会把音乐压到三成再响，两条音轨不打架。
- **私密音效只有真文件。** 早期版本有 17 个内置合成音（汽笛、猫叫、弹簧、悲情小号、白噪音、5 段浏览器 TTS……），现场一次都没让人笑过，还把自己传的挤到第二栏去，所以全删了，只留 7 个游戏自己的提示音（ding / tick / buzzErr / win / boom / wolf / siren）。现在能放的只有主持台**自己传的**：第二个上传口传的私密音效，和第一个口传进曲库的歌。库里一个文件都没有时，「放」和「灌杂音」两个按钮是灰的，面板上直接写着去哪传 —— 不会静默失败让你以为耳机坏了。老存档里如果还留着 `laugh`、`noise` 这种已经删掉的内置名字，打开面板时自动落到第一个能用的真文件上。
- **舞蹈狼人杀的音乐只走耳机。** 这是唯一一个必须全员戴耳机的游戏 —— 音乐一旦外放，狼王也听见了，游戏立刻失效。默认是每个手机本地合成的同一首循环舞曲，不传输任何音频，20 个人同时「听歌」也不占带宽；也可以在主持台把曲目换成音频库里的真歌，那时每台手机各拉一份自己缓存、各自 seek 到同一秒。**音量只有主持人能调**：手机端没有滑杆，不然谁都可以装「我这儿也没声音」。狼王那台的界面（进度条、百分比）完全一样，只是不出声。
- **进度条只有主持台能拖，拖的是全场。** 玩家端只显示 `0:23 / 1:00` 和进度，不能拖。如果每台手机各拖各的，好人之间也踩不到一起，这游戏就没有参照物了。主持台拖一下，全场一起跳到同一秒，狼王那台跟着跳但不发声。注意进度条的时间轴是**本轮跳舞时长**（默认 60 秒），不是歌曲长度。
- **抢跑不是罚出来的，是按不出来的。** 听歌识曲的按钮在开抢时刻之前是灰的，物理上按不下去；服务端再兜一道，早到几十毫秒只回一句「还没到」，不扣分、不禁答。报数抢答保留原来的抢跑判负 —— 那个游戏本来就是「看谁敢抢」。
- **选完游戏，投屏先出规则卡。** 3 条规则 + 一句口号 + 二维码，主持台上同步摆着同一份字。现场顺序本来就是「选游戏 → 讲规则 → 发词」，规则卡要是等到开局才出现，在那之前大屏是空的，也没人看。收起靠主持人做的**第一个真动作**（发词开局 / 开始 / 放歌），不用再按一次「我讲完了」—— 那个按钮在现场一定会被忘掉，然后大屏一直停在规则页，全场以为卡住了。开局前换词库、改人数、拖进度条都不算开始，卡片留着。新来两个人没听到规则，点标题右边的「规则卡」随时重新打上屏。
- **身份卡遮罩外面一个字都不能因身份而不同。** 副标题、边框颜色、按钮文案，全都得对所有人一字不差。紫色边框等于直接告诉旁边的人他是狼。

## 比分与队伍

- **进场不自动分队。** 人陆续到场，自动分队只会把他们拆散，还得一个个改回来。等人都到齐了，点一下「分组」按到场顺序左右交替分成 A / B（人数差最多 1）；「重新分组」会先打乱再分。
- 左栏按队伍分区显示，一队的人排在一起，队头上有队伍总分和 `-1 / +1`，点分数可以直接改成某个数（现场「这轮算 5 分」比连点加号快）。
- 想换队：点一个玩家，用下面的「A 队 / B 队 / 移出队」。
- 点一个玩家，最下面还会出现「耳机里放」——选一段音效点「放」，只有他那台手机响（详见下面「私密音效」那条）。没戴耳机的人这一栏不出现。
- 游戏结算会自动加分（猜对 +3、卧底赢 +5 等），也可以手动 +1 / -1。
- 大屏底部常驻两队比分，领先的一方高亮。
- **围观下注的分数单独记**（大屏收工榜写「正赛 9 · 押注 2」）：押中 +2，不进正赛分，免得没上场的人靠押注冲到第一。
- 「整场重置」清比分留人；「清空玩家」适合换一批人。

## 一晚怎么开

### 提词器（开局后自动出现）

开局之后，中栏不再是按钮面板，换成三行字：**这一步是哪一步 / 你要说的那句话 / 下一步是什么**，下面三个键：完成、跳过、再说一遍。台词存在 `games/<id>/script` 里，跟着游戏走；目前狼人杀（8 步）、谁是卧底（6 步）、传声筒（5 步）写了全套，其余游戏用通用三段式（开始 / 进行中 / 结算），右下角会标「通用脚本」。

- 「完成」「跳过」都往下走一步，走到最后一步就停住，不会绕回开头。
- 「再说一遍」不改进度，只把当前这句弹出来（方便你刚才说岔了）。
- 要临时改设置就点「展开面板」，原来的信息行、按钮区、表格都回来；再点收起又回到提词器。
- 大厅阶段不显示提词器——人到齐前要分组、选游戏、传音频，空着反而碍事。

**顶栏「侧栏 ◂」** 把右侧栏（音频库 + 操作记录）整块收起来，中栏变宽；再点一下展开。音频是「开演前设一次」的东西，不该常驻占四分之一屏。

### 玩家端：一句话指令与进度

每张玩家视图最上面多了一行**「现在该干嘛」**（按住看词 / 选一个再确认 / 轮到你 / 等下一步），副标题下面多了一行**「第 2 轮 · 场上 5 人」**。这两行由 core 统一加，13 个游戏不用改；有游戏自己写了更贴切的指令，就用它的。

轮到你的时候手机会震一下——但 iOS Safari 不支持震动，所以视觉提示（那行指令）必须独立成立，不能只靠震。

### 结算页的四个出口（2026-11-24 修）

本局结束后那一行现在有：**同批人再来一局 / 换个游戏 / 今晚收工**，第二排是 **返回本局 / 打印名单**。

- **人数不够时**，「再来一局」直接灰掉并写成「再来一局（还差 3 人）」，鼠标悬停能看到「需要 4 人在线，现在 1 人」。
- **失败不再是死路**：即使点到了（或开局报错），状态会退回「已选游戏、还没开始」——大屏重新出规则卡、主持台出现「开始」按钮，不会再卡在「显示 playing 但其实没开」。
- **返回本局**：误点「本局结束」能退回去。只关结算覆盖层，不动这一局的进度，也不回滚已经记下的历史分。

### 现场反馈修复（2026-11-23）

- **规则卡带人数**：大屏上写「需要 N 人起 · 现在 M 人在线」，不够会标「还差几人」。
- **选完游戏先出规则**：不再直接进游戏，大屏放规则，主持台出现「开始：游戏名」，点一下才开局。
- **开局前指定人**：你画我猜可以在选游戏阶段就点「选中的人下一局当画手」；传声筒、接力猜词可以在开局前挑棒次（那会儿还没发词）。
- **报数抢答大屏**：改成大字「准备… / 抢！」，不再是空柱状图。
- **音频起点**：素材库多一个「起点（秒）」，留空从头播，填了就从那秒开始。
- **笨蛋杀手接头动作**：系统从 12 个具体动作里随机抽，不再由玩家自己编；主持台有「重抽接头动作」。
- **围观下注**：结算后多了「清掉」，不会卡在只剩「再开一轮」那一行。
- **重复就打飞**：分组行标了人数（「第 1 组（3 人） 甲/乙/丙」），结算页写清本轮主题。
- **打印名单**：「今晚 → 打印名单 → 打印」，A4 横向一张手写记分表（名字 + 10 轮空格 + 备注）。
- **数字炸弹**：踩中炸弹这一轮立刻结束、当场揭晓，不再换新炸弹继续。
- **你们认了吗**：柱状图上方补了题目和进度抬头（之前 title 没被渲染，大屏只剩柱子）。

### 素材库（右栏第一块）

音频和词库合成一个入口，上面两个分区切换：

- **音频**：曲目下拉 + 播放 / 暂停 / 停 / 删。「试听」改成了「播放」；内置合成节拍不再占一个选项——只有它真在用（没传过歌，或刚删掉正在播的那首）才显示一行「内置节拍（兜底）」。删曲目要点两下（第一下变「确认删」），删掉正在播的那首会自动落回兜底，不会静音。
- **词库**：列出各词库和条数，点「打开词库管理」进原来的增删界面。

顶栏原来那个「词库」按钮已经去掉，入口只剩这一个。

### 仪式动作现在「挂住」

除倒计时外，六个动作都**不再自动撤**：发身份、宣布死亡、揭晓、静场、推大字会一直挂在投屏上，直到你点「撤掉」（仪式那排最右边，红色）。倒计时保留自动结束——它自带终点。

防挡是写死在代码里的：换游戏、开新局时自动收掉。所以忘了撤也不会带到下一局。

### 惩罚卡可以自己加（「今晚 → 惩罚卡 → 管理」）

标题（8 字）、清爽说法（30 字）、酒桌说法（30 字，可不填）、停留秒数（3–20）。加进去就进抽卡池，抽满一轮才洗牌；不想要就点「删」。存在 `packs/_punish.json`，和词库的自定义一个路子，打包时不带。

### 接力猜词可以自己挑棒次

开局先出一排空位，手机上点「就这一棒」，先到先得；被占的棒次对别人是灰的。没人挑的位置由主持人按「补位并开始」随机补——不惩罚性安排。

### 四个游戏改成「大屏控场」

这四个不再让玩家掏手机，改由你控场；判定统一走「裁决」那一条。

- **数字炸弹**：你在主持台输入数字替当前这位报（`1–100` 之间），大屏显示区间。手机只写「轮到你，看大屏」。
- **报数抢答**：默认大屏——倒数结束喊出来，你用「裁决」按顺序点人，第 1/2/3 名分别 +3/+2/+1。主持台有「切回手机抢答」，较真的局可以用回毫秒判定。
- **听歌识曲**：歌从音响外放，听出来直接喊；你在「裁决」里判对（+3）或判错（扣 1 且这轮禁答）。
- **重复就打飞**：音乐停后大屏直接给分组（**2–4 人一组**，按在场人数随机，不会出现一人一组）和主题，手机上只提醒「看大屏」。

另外两个是「半改」：

- **你画我猜**：加了「切到举手判分」和「选中的人当画手」。举手模式下手机不再有输入框，答案是喊出来的，你判对才 +3；切回去手机提交照旧，统计也照旧。
- **传声筒**：去掉了「我传完了」和最后一棒的输入框，改由你点「下一棒 →」推进；最后一棒说出来或写纸上，你判对判错。**杂音保留**，开关在主持台。

### 裁决台（「仪式」那排的「裁决」）

手机不参与的局，判定回到人身上：点「裁决」→ 点一个名字 → 对 / 错。判完自动清掉选中，记录留在操作日志里。开「打点」时点名字只记一次参与（称号和复盘靠它），不判分。

判对加多少分由游戏自己声明（`games/<id>/index.js` 的 `judge` 钩子），底座不替游戏定分数。

### 手机遥控（顶栏「⋯ → 手机遥控」）

点开是一个 6 位临时码 + 二维码。手机扫进 `192.168.x.x:3321/remote`，输码就能用：

- **完成 / 跳过 / 再说一遍**：和提词器上那三个键一样
- **四个仪式**：静场、倒计时、发身份、揭晓（另外「推大字」有输入框）
- **这一局**：游戏自己的主按钮（重开一局、下一位发言、开始投票、计票…），只取前四个

**权限边界写在核心里**：遥控只能推进流程。换游戏、清空玩家、重置比分、替玩家投票——全都会被拒。码 4 小时过期，随时可换；换游戏/清人这些动作仍然只能在那台电脑上做。

为什么不直接用主持台地址？那个 URL 里带着长期密钥，念给旁边人等于把整台机器交出去。

### 名场面与综艺结算

「操作记录」标题旁有个「记一段」：一句话（40 字内）记下刚才那段，比如「老周说他从来没抽到过狼」。

**综艺模式的结算页因此换了样子**：标题从「本局排行」变成「本局结束」，先摆出这一局记下的名场面（最多 3 条），下面只排一行名字——**分数不上屏**。切到比赛模式就回到原来的排行和分数。

### 惩罚卡（中栏「仪式」那一排里）

点「惩罚卡」，投屏盖上一张卡片。右边有个口径按钮，**清爽 / 酒桌**两套说法一键切（默认清爽，酒桌时按钮变红）：**唱一句 / 夸三个人 / 学一个人 / 给输家打广告 / 定住五秒 / 编一句台词 / 对着镜头道歉 / 说唱一句 / 数一遍人 / 敬一杯 / 说个秘密 / 慢动作走三步**。卡片按各自时长自动撤（5–10 秒）。

十二条都不需要道具、场地和体力。抽过的先进「已抽」池，**12 张全抽完才洗牌**——裁到最近 5 张的话，第 6 张就可能撞回第 1 张，现场会以为程序坏了。

### 投屏的三处节奏（S1 / S4 / S5）

- **换游戏转场**：切换游戏时投屏压暗 0.45 秒，中间是大号游戏名。只在客户端做，同一局刷新不闪。
- **投票倒计时**：谁是卧底、狼人杀、你们认了吗进入投票阶段，投屏右下角出现 60 秒胶囊，主持台标题旁同步显示；到点变「超时」，没投的算弃权（不替任何人代投）。倒计时由 core 统一管，游戏只声明「现在是不是在投票」。
- **抢答只给档位**：报数抢答的名次表多一列「时间差」，只写「0.02 秒 · 几乎同时 / 明显先到」，不出毫秒。另外加了「判并列」「三局两胜」两个键，只写记录、不自动加分。
- **逐条揭晓**：谁是卧底计票之后，投屏不直接把票数甩出来，而是一条条放「甲 → 己」，主持台点一次出一条，8 秒没人点自动往下；最后一条是汇总（共几票、谁最高），放完回到正常结算。

### 提交完的完成态

投票、猜词、抢答这类「交上去就算完」的动作，交完手机上会出现一个绿色对勾 **✓ 已提交**，下面那行指令变成「已提交，还差 3 人」；全交齐了是「都交齐了，等主持人」。目前覆盖你们认了吗、谁是卧底、狼人杀、传声筒、听歌识曲五个游戏（数字炸弹是轮流报数，没有「提交」这回事，没加）。

### 仪式动作（中栏那一排）

六个通用动作，任何游戏下都能单独触发：**发身份 / 宣布死亡 / 揭晓身份 / 静场 / 倒计时 / 推大字**。投屏出全屏动画，声音从主持台这台电脑出（投屏永不发声那条红线不破）。「推大字」右边是个输入框，写一句（最多 20 字）点「推上屏」，15 秒后自动撤。

游戏脚本里的 `fx` 字段引用的就是这六个名字，动画由 core 统一实现，游戏自己不写动画——各写各的，观感就散了。

### 模式：综艺 / 比赛（今晚面板里切）

默认是**综艺模式**：投屏不摆比分条，称号换说法（分最高的叫「最佳搅局者」、动手最多的叫「最强信念感」）。切到比赛模式就是原来的样子，MVP、比分条都回来。**分照加，只是不摆出来**——中途切回去，数据是连续的。

### 节目单（顶栏「今晚」）

五套模板：**自由模式 / 标准一晚 / 人多热场 / 综艺同款 / 分队对抗**。

- 标准一晚：暖场（报数炸弹）→ 主游戏（谁是卧底）→ 惩罚 → 收尾，一共 5 项。
- 「下一项」按顺序往下走，点到底停在最后一项，不会绕回开头；想重来就重选模板。
- 综艺同款：报数抢答 → 舞蹈狼人杀 → 整一个人 → 笨蛋杀手 → 你们认了吗。坡度是「体力 → 信息差 → 推理」，收尾最轻；中间「整一个人」不是游戏，轮到它就用左栏「耳机里放」。
- **人数不够、或者有人没戴耳机，选模板的那一刻面板上就标出来**（红条 + 一句提示），不用等开局才发现。
- 惩罚那一项不带游戏，投屏清空，主持人自己发挥。
- 自由模式下没有节目单，直接在上面选游戏。

### 自动推进（工具条上的「开自动」）

只有游戏自己声明了「下一步是什么、叫什么、默认几秒」，工具条才会出现这一组：

```
可自动推进「下一位」   [30 秒 ▾] [开自动]
自动中 · 每 30 秒「下一位」· 已点 7 次   [停自动]
```

可选 15 / 30 / 45 / 60 秒。四道保险随时会停：不在局中、已经结算、动作不存在、连续失败 3 次。每次自动执行都写进右下角操作记录，事后能查是谁点的。

### 围观下注（工具条上的「开下注」）

没在局里的人（卧底局没抽中的、狼人杀出局的、这一轮没轮到的）手机上整屏变成「押一个」，从场上的人里挑一个。

- 结算前可以改，算最后一次——现场就是会反悔。
- 不能押自己。
- 大屏只报「N 人押了」和结果，**不报谁押了谁**。
- 主持台在左栏点一个赢家，再点「结算给选中的人」。

### 空档表情

等下一局那几十秒，手机上点一下表情就飘到投屏上。只有 6 个，不能打字——现场一旦能打字就会有人开始骂人。

### 收工：称号 + 复盘

一局结束，工具条整条换成三个出口：**同批人再来一局 / 换个游戏 / 今晚收工**。

「今晚收工」上投屏的是总榜：名次、名字、称号、总分（正赛 + 押注）。称号一人一个，按优先级发：今晚 MVP → 神预言（押注最高）→ 最忙的一双手 → 静观其变（动作最少的那一个）→ 稳定输出 / 气氛组。

顶栏「复盘」出今晚的记录：几局、每局分数条形、参与度（几局、平均动作次数），底部「导出 CSV」可以留档或发群里。

### 皮肤与语音

「今晚」弹层里两行设置：

- **语音播报**：「时间到」「本局结束」「今晚收工」从这台电脑出声（浏览器自带语音，不用联网录音）。投屏那台不念。第一次要点一下「试一句」把浏览器叫醒。
- **皮肤**：日常 / 过年（红金），只换颜色不动布局，大屏和手机一起换。

## 断线、刷新、重启会怎样

| 情况 | 结果 |
|---|---|
| 玩家刷新页面 | 点一下「继续」，回到原来的位置，不重复占位 |
| 手机切微信再回来 | 屏幕常亮自动续上，音效可用 |
| 手机断 Wi-Fi | 顶部黄条提示重连，恢复后自动接回；45 秒内都算「还在」 |
| **服务被关掉 / 电脑重启** | 每 2 秒存一次档，重启后自动恢复玩家、比分、当前游戏 |
| 主持台标签页被误关 | 音频会停，重新打开点「播放」即可；局面不丢 |
| 上次那批人早走了 | 不在局中时，离线超过 30 分钟的会在启动、或下一个人扫码时自动清掉；左栏也有「清离线」一键清 |
| **局中有人掉线** | 局中一律不自动清人，只在左栏标「离线 · N 分钟」——长局（狼人杀 + 中场休息）不会把人清掉重扫码。确实走了不回来的，点「清离线」手动清 |

刷新后必须点一下「继续」，是因为浏览器规定没有用户手势就不许出声——这不是 bug，绕不过去。

## 加一个新游戏

新建 `games/你的游戏/index.js`：

```js
module.exports = {
  id: 'mygame',
  name: '我的游戏',
  desc: '一句话说明',
  minPlayers: 2,
  slogan: '投屏上那句口号',              // ≤ 20 字
  rules: ['第一条', '第二条', '第三条'],  // 必须 3 条，每条 ≤ 24 字（三米外念得下来）
  init() { return {}; },                 // 初始状态
  setup(room, cfg, ctx) {},               // 开局
  actions: {                              // 玩家动作（host_ 开头的是主持专用）
    submit(room, ctx) {},
    host_next(room, ctx) {},
  },
  playerView(room, pid) {                 // 这个人该看到什么
    return { type: 'word', text: '词', hold: true };
  },
  hostView(room) {                        // 主持台的控制面板
    return {
      info: [{ label: '进度', value: '1/3' }],
      controls: [{ kind: 'btn', action: 'host_next', label: '下一位', style: 'primary' }],
    };
  },
  screenView(room) { return { type: 'podium', big: '1 / 3' }; },
};
```

`slogan` 和 `rules` 是开局面板的内容：选完游戏就打上投屏，主持台照着念。
缺了 `check.js` 直接报错 —— 空着一张规则卡，现场等于没有这个功能。

前端只认 7 种控件，正常情况下不用碰 HTML：

`word`（私密词卡，按住才显示）· `choice`（选项/投票）· `answer`（输入）·
`buzz`（抢答）· `timer` · `text` · `list`

## 出问题先看这里

| 现象 | 原因 | 处理 |
|---|---|---|
| 手机打不开地址 | 不在同一 Wi-Fi / 防火墙拦了 | 先对着大屏上的网名核一遍手机连的是不是这条；再放行 Node.js 的专用网络 |
| 大屏只写「和导演台连同一个 Wi-Fi」 | 电脑走的是网线，或系统不让问 Wi-Fi 名 | 正常情况，不影响玩；要显名字就换成 Wi-Fi 上网 |
| 扫码进去空白 | 用了公网地址 | 用主持台显示的那个 `192.168.x.x` |
| 主持台 403 | 用了不带密钥的局域网地址 | 用终端打印的带 `?k=` 那条，或本机 `localhost` |
| 点了播放没声音 | 还没启用音频 / 输出设备不对 | 点右上角「启用声音」；确认 HDMI 或 3.5mm 接好 |
| 音乐自己停了 | 电脑休眠 / 标签页被切走 | 关掉休眠；音频守护会自动拉回，仍不行就手动再点播放 |
| 有人听不到私密音效 | 没戴耳机 / 手机静音 / 蓝牙连错设备 | 看主持台卡片上的「无耳机」标记 |
| 抢答有人不服 | 网络和手机性能差异 | 规则上做三局两胜，不承诺绝对公平 |
| 大屏没画面 | HDMI 输入源选错 | 开场体检里确认 |
| 主持台一片空白 | 脚本语法错误 | `node tools/check/check.js` 会直接指出来 |

**开场前 30 秒体检**：主持台右上角「开场体检」，会告诉你在线人数、谁没戴耳机、谁可能灭屏、投屏开没开。

```bash
node tools/check/check.js          # 语法 + 插件接口 + 词库格式 + pacing 声明

BASE=http://127.0.0.1:3321 node tools/check/briefcheck.js   # 75 项开局面板
BASE=http://127.0.0.1:3321 node tools/check/extracheck.js   # 217 项：下注/自动推进/表情/称号/节目单/提词器/复盘/皮肤
node tools/dev/revtest.js        # 反测：故意改坏 8 处实现，看用例抓不抓得住
```

全量 13 个脚本 / 787 项：

```
check 54 文件 · smoke 157 · hardcheck 59 · modecheck 71 · notecheck 25
briefcheck 71 · extracheck 217 · packcheck 58 · uicheck 52 · holdcheck 27
linkcheck 11 · dragcheck 17 · audiocheck 22
```

`check.js` 存在的理由：上一个项目在主持台里多写了一行 `let es`，导致整段脚本不执行、现场全废，而且肉眼看不出来。这个脚本 3 秒就能发现。

`extracheck` 前半是纯逻辑（直接 `require` 那几个模块），后半走接口和 SSE —— 逻辑对但接口没接上，现场一样是点了没反应。

`revtest` 是给测试本身做体检：临时改坏一处代码、起个临时端口的服务、跑 extracheck，看该红的那几条有没有红，跑完自动还原。第一轮 8 条只抓到 6 条，漏的两条说明用例写得不严，补完才 8/8。

## 已知限制

1. **主持人不能下场玩**（这是设计前提），所以要有一台电脑专职当导演台。
2. **音频单点**：电脑关机 = 音乐停。现场别关那个终端窗口。
3. **抢答精度**：同一 WiFi 下裁决差在 20ms 量级，摸不到「绝对公平」，建议三局两胜。
4. **私密音效依赖耳机**，外放等于公开，靠进场勾选自报 + 主持台标记兜着。
5. **词库口味自控**：`packs/` 里的词是给你改的，别在现场翻出不合场合的题。
6. 上传的曲目请自行确认版权与场合；内置合成节拍零版权，可放心用。
