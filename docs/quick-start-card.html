聚会游戏机 · 十分钟开场

第一次用看这一页就够。细节翻《操作手册》。
1 起服务

插电，双击 start.bat。
等黑窗口里出现一行
http://192.168.x.x:3210

2 投屏

投屏电脑打开
…:3210/screen
按 F11 全屏。

3 扫码

大家扫投屏上的二维码
进 /play，戴上耳机。
主持台点「选游戏」开局。

卡住了先看这里

  • 扫不开：手机和电脑不在同一个 Wi-Fi。
  • Windows 弹防火墙：点「允许」，尤其「专用网络」。
  • 投屏没声音：正常。声音只从主持台那台电脑出，接 HDMI 或 3.5mm，别用蓝牙。
  • 页面打不开：黑窗口被关了。重新双击 start.bat。

第一次别做这四件

  • 别一上来玩狼人杀（规则重，主持人会乱）。
  • 别开「自动推进」（还不知道它会替你点什么）。
  • 别开两个投屏窗口（画面会互相抢）。
  • 别把主持台地址念给全场（带密钥）。要帮忙推进，用「⋯ → 手机遥控」的 6 位码。

开演前 90 秒自检

  • 投屏上有二维码，下面是 …/play
  • 手机输名字能进，投屏显示「已加入 N 人」，人数对得上
  • 点一次「启用声音」，听到提示音
  • 顶栏「开场体检」全绿

今晚怎么排（照抄这两行就行）

6–8 人 / 2 小时 报数抢答 → 谁是卧底 → 惩罚 → 传声筒 → 你们认了吗
8–12 人 / 3 小时 报数抢答 → 你画我猜 → 惩罚 → 舞蹈狼人杀 → 笨蛋杀手 → 收尾
一晚 3–4 个游戏就够：热身 → 主游戏 → 惩罚 → 主游戏 → 收尾。收尾一定要轻——结束时的情绪会被记住整晚。
