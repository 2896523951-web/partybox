# 第一次用 · 十分钟上手 & 一晚怎么排

> 2026-11-21 · 聚会游戏机
> 这份文档解决两件事：**第一次用怎么开起来**，以及**一晚上玩什么、按什么顺序**。
> 手册（23 页）是查细节用的；这份是开箱即用的那一页。

---

## 一、十分钟上手

### 三步

| 步骤 | 做什么 | 大概多久 |
|---|---|---|
| 1 | 插电，双击 `start.bat`，等黑窗口里出现一行 `http://192.168.x.x:3210` | 30 秒 |
| 2 | 投屏那台电脑打开 `http://192.168.x.x:3210/screen`，按 F11 全屏 | 30 秒 |
| 3 | 大家扫投屏上的二维码进 `/play`，戴上耳机 | 2 分钟 |

然后就剩一件事：**主持台（`/host`）选一套节目单，点开局**。

### 三件一定会遇到的事

- **扫不开**：手机和电脑不在同一个 Wi-Fi。电脑连的是 5G、手机连的是另一个频段，也会不通。
- **Windows 弹防火墙**：点「允许访问」，尤其是「专用网络」。点了拒绝就得去防火墙里改回来。
- **投屏没声音**：正常。投屏永远不发声，声音只从主持台那台电脑出去——接 HDMI 或 3.5mm，别用蓝牙（延迟半秒，抢答会判错）。

### 第一次别做这四件事

1. 别一上来玩狼人杀或笨蛋杀手——规则重，主持人第一次念会乱。先用报数抢答、你画我猜这种两分钟讲完的。
2. 别开「自动推进」——第一次用还不知道它会替你点什么。
3. 别投屏同时开两个窗口——两个 `/screen` 会互相抢，画面跳。
4. 别把主持台地址念给全场——那串地址带密钥。要让人帮忙推进，用「⋯ → 手机遥控」的 6 位码。

### 90 秒自检（开演前）

- 投屏上能看到二维码，且二维码下面是 `192.168.x.x:3210/play`
- 手机上打开 `/play` 能输名字，且显示「已加入 N 人」
- 主持台左栏人数和你数的人数一致
- 点一次「启用声音」，听到提示音
- 主持台顶栏「开场体检」全绿

## 二、一晚怎么排

### 先立三条原则

1. **一晚 3–4 个游戏，不要 6 个。** 换场本身就要 5 分钟（讲规则、分队、上厕所）。游戏越多，真正在玩的时间越少。
2. **坡度：热身 → 主游戏 → 惩罚 → 主游戏 → 收尾。** 重口味的放中段，收尾一定要轻。
3. **每个游戏 15–25 分钟**，含讲规则和结算。超过 30 分钟就开始有人低头看手机。

### 主推 A：6–8 人 / 2 小时（最常见）

| 时间 | 内容 | 说明 |
|---|---|---|
| 00:00–00:10 | 开场 | 扫码、戴耳机、讲三条规矩 |
| 00:10–00:25 | **报数抢答** | 热身，同时试设备（抢答最考验网络） |
| 00:25–00:30 | 惩罚卡 ×1 | 给热身最后一名 |
| 00:30–00:55 | **谁是卧底**（2–3 局） | 主游戏，靠信息差，不需要体力 |
| 00:55–01:05 | 休息 | 喝水、加饮料、上厕所 |
| 01:05–01:25 | **传声筒**（分队，2 轮） | 分工合作，笑点集中在最后一棒 |
| 01:25–01:30 | 惩罚卡 ×1 | 输的那队出一个 |
| 01:30–01:50 | **你们认了吗** | 收尾，全员参与、不淘汰 |
| 01:50–02:00 | 结算 + 名场面 | 收工榜、合影 |

对应节目单：**标准一晚**（把第二项换成传声筒即可）。

### 主推 B：8–12 人 / 3 小时

| 时间 | 内容 | 说明 |
|---|---|---|
| 00:00–00:15 | 开场 + 分队 | A/B 队，后面两轮用得上 |
| 00:15–00:35 | **报数抢答** | 全员，热身兼试网络 |
| 00:35–01:05 | **你画我猜**（分队） | 画的人轮换，别让一个人一直画 |
| 01:05–01:15 | 惩罚 + 休息 | 输的队出一个人做惩罚卡 |
| 01:15–01:45 | **舞蹈狼人杀** | 体力局，需要全员戴耳机 |
| 01:45–01:55 | 休息、补水 | 体力局之后必须停一下 |
| 01:55–02:25 | **笨蛋杀手** | 推理局，人还清醒的时候玩 |
| 02:25–02:30 | 惩罚卡 | |
| 02:30–02:55 | **你们认了吗 / 听歌识曲** | 收尾，坐着也能玩 |
| 02:55–03:00 | 收工榜 + 名场面 | |

对应节目单：**人多热场**（顺序微调即可）。

### 备选 C：12 人以上 / 团建 / 2.5 小时

接力猜词（分队）→ 听歌识曲 → 舞蹈狼人杀 → 惩罚 → 你们认了吗

关键是**没有「干看」的人**：四个游戏都是全员同时动手，不需要等轮次。

### 备选 D：4–6 人 / 家庭 / 1.5 小时

好奇宝 → 你画我猜 → 谁是卧底 → 收尾

避开狼人杀、笨蛋杀手：人少时推理局容易变成两个人对质，其他人插不上话。

### 六条排法规则（推荐模板都按这个来）

1. **第一个游戏必须两分钟能讲完规则**——它同时是设备试运行。
2. **需要全神贯注的放中段**，别排到十点半以后。
3. **体力游戏不放最后**，收尾要能坐着。
4. **惩罚卡插在气氛低谷**，别连着两个重口味。
5. **收尾游戏要「输了也不难受」**——结束时的情绪会被记住整晚。
6. **换场靠转场动画 + 提词器第一步**，主持人不用背流程。

## 三、酒桌版（可选）

默认十二条惩罚卡是清爽向的（不劝酒、不含身体接触）。酒桌上想加一点，「仪式」那一排的「惩罚卡」右边有个口径按钮：点一下从**清爽**切到**酒桌**，按钮变红提醒你别忘了切回来。只换说法，不换结构——12 张卡、抽满才洗牌、不记分，全都不变。

下面这张表就是程序里那套酒桌说法，主持人也可以直接照念。

| 原卡 | 酒桌版说法 |
|---|---|
| 唱一句 | 唱一句，跑调就喝一口 |
| 夸三个人 | 夸三个人，被夸的喝 |
| 学一个人 | 学一个人，猜错的人喝 |
| 给输家打广告 | 十秒广告，全场举杯 |
| 定住五秒 | 定住五秒，动了喝 |
| 编一句台词 | 用上一局的词说台词，说不出来喝 |
| 对着镜头道歉 | 道歉，理由越荒唐越好，全场表决过不过 |
| 说唱一句 | 说唱一句，卡住就喝 |
| 数一遍人 | 用方言数人，数错重来，重来一次喝一口 |
| 敬一杯 | 对全场说祝酒词，十秒内说完 |
| 说个秘密 | 编一个能过审的秘密，被识破喝 |
| 慢动作走三步 | 慢动作走三步，笑场喝 |

**四条饮酒节奏（比惩罚本身重要）**

1. 先吃后喝，空肚子不上桌。
2. 每小时一杯水，主持台负责提醒。
3. 有人说开车、吃药、不舒服——**立刻切无酒版**，不解释、不劝。
4. 只做动作换酒，不罚酒。「喝一口」默认是抿一下，允许换饮料。

酒桌建议切**综艺模式**（今晚面板最下面）：不摆分数，输赢不容易较真。

## 四、与产品功能的对应

| 你要做的事 | 点哪里 |
|---|---|
| 看今晚路线 | 顶栏「今晚」→ 选模板 |
| 知道下一步说什么 | 开局后中栏自动变提词器 |
| 走开也能推进 | 顶栏「⋯ → 手机遥控」，手机输 6 位码 |
| 让人安静 / 宣布出局 / 倒计时 | 中栏「仪式」那一排 |
| 临时通知全场 | 「仪式」→ 推大字（20 字，15 秒自动撤） |
| 结束一局有仪式感 | 「惩罚卡」抽一张 |
| 记下好笑的一句 | 「操作记录」旁的「记一段」 |
| 综艺 / 比赛模式 | 「今晚」面板最下面 |
